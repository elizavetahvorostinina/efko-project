# EFKO — учебные работы по системному анализу

В этом репозитории собраны отдельные учебные работы по подготовке функциональных требований, составлению сценариев тестирования и моделированию бизнес-процессов в BPMN. Материалы выполнены по разным задачам и **не являются частями единого проекта**.

## Функциональные требования

Функциональные требования подготовлены в рамках учебных заданий; разделы вне объёма задания отмечены в документах.

- [Автоматизация выгрузки кадровых данных](./requirements/ft-01-automation-of-personnel-data-export.docx) — требования к передаче сведений о кадровом переводе между системой кадрового учёта и ИС «Сотрудники»: пользовательские роли, сценарий работы, статусы и правила заполнения полей.
- [Автоматическое формирование обходного листа](./requirements/ft-02-automatic-generation-of-the-printed-form.docx) — требования к формированию печатной формы на основании документа «Увольнение», включая состав полей и правила их заполнения.
- [Автоматизация выгрузки персональных данных сотрудников](./requirements/ft-03-automation-of-employee-data-export.docx) — требования к обмену данными между 1С и общим хранилищем, включая сценарии выгрузки, сопоставление полей (маппинг) и требования к передаче отдельных категорий данных.

## Сценарии тестирования

- [Приём сотрудника](./test-protocols/test-protocol-01-automation-of-the-employee-recruitment-process.docx) — проверки оформления приёма в 1С:ЗУП и передачи кадровых данных в ИС «Сотрудники».
- [Кадровый перевод](./test-protocols/test-protocol-02-automation-of-the-personnel-transfer-process.docx) — проверки изменения кадровых данных, проведения документа и передачи изменений.
- [Формирование обходного листа](./test-protocols/test-protocol-03-automatic-generation-of-the-bypass-sheet-form.docx) — проверки формирования и печати обходного листа при увольнении.
- [Изменение данных сотрудника](./test-protocols/test-protocol-04-changing-employee-data.docx) — проверки редактирования, сохранения и повторного отображения данных сотрудника.

## Представленные навыки

- Описание пользовательских сценариев и функциональных требований.

- Моделирование бизнес-процессов и подпроцессов в BPMN.
